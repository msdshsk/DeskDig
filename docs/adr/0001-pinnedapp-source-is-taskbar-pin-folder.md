# PinnedApp の取得元はタスクバー固定フォルダとし、独自のアプリ登録機能を持たない

Launcher に並べるアプリを、このツール独自に登録させる案と、Windows のタスクバー固定状態を読み取る案があった。ユーザーが既に 40〜50 件をタスクバーに固定しており、二重管理を避けたいこと、登録作業そのものが使わなくなる原因になることから、タスクバー固定フォルダのショートカットを唯一の取得元とし、このツール側では並び順だけを持つことにした。

## Considered Options

- 独自登録（ドラッグ&ドロップでアプリを追加）。柔軟だが二重管理になる。
- スタートメニューのピン留めを読む。形式が非公開バイナリで壊れやすい。
- タスクバー固定フォルダを読む（採用）。集合は確実に取れるが、並び順はレジストリの非公開形式にしか無い。

## Consequences

- 並び順はこちらで独自に保存する。タスクバー側の並び替えには追従しない。
- 固定されていないアプリを Launcher に出したい要望が出た場合は、「タスクバーに固定する」が回答になる。それで足りなくなった時点でこの ADR を見直す。
