# 仮想デスクトップは公開 API の範囲でのみ扱い、非公開インターフェースを使わない

他の仮想デスクトップにあるウインドウを一覧に出すには「現在のデスクトップにあるか」が分かれば足り、これは公開 COM インターフェースで取れる。デスクトップの名前・一覧・明示的な切り替えは非公開インターフェースにしか無く、Windows のビルド更新ごとに識別子が変わって壊れる前例が多い。常駐ツールが OS 更新のたびに起動不能になる事態を避けるため、公開 API の範囲に限定し、切り替えは「他デスクトップのウインドウを前面化すると OS が自動で切り替える」挙動に委ねる。

## Consequences

- 一覧上は「現在のデスクトップ」と「他のデスクトップ」の二分表示までで、デスクトップ名は出せない。
- 将来デスクトップ名を出す場合は、非公開 API 依存部分を別の差し替え可能な層に隔離し、失敗時に二分表示へ退避する設計を条件とする。
